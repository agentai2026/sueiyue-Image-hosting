岁月图床

把回忆收进云端，把链接留在指尖。

开源个人图床，支持 Cloudflare Workers / Pages 与 Docker 部署。本站为项目主页；完整上传与存储能力请按仓库说明自行部署。

查看仓库 部署指南

三步开始

克隆仓库后，本地预览或部署到 Cloudflare / Docker 即可使用完整图床功能。

克隆项目

从 GitHub 获取源码：git clone 本仓库到本地。

本地预览

执行 npm install 与 npm start，访问 localhost:8080。

上线部署

配置 Wrangler binding 后运行 npm run deploy:worker，或使用 Docker Compose。
